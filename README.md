# 2048 Game 🎮

A classic **2048 puzzle game** implemented using **vanilla JavaScript**, **HTML**, and **CSS**.  
The goal of the game is to combine tiles with the same numbers to reach the **2048 tile**.

---

## 🔗 Demo
You can view the live demo here:  
👉 [2048-game]( https://moddderi.github.io/2048-game/)

---

## 🧩 Game Rules

- The game is played on a **4×4 grid**.
- Use the **arrow keys** (⬅️ ⬆️ ➡️ ⬇️) to move the tiles.
- When two tiles with the same number collide, they **merge into one**.
- After each move, a new tile (2 or 4) appears on the board.
- The game ends when no more moves are possible.

---

## 🚀 Features

- Smooth tile movement and merging
- Score tracking
- Restart game functionality
- Responsive design
- Pure JavaScript (no frameworks)
